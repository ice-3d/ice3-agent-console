ICE3 Agent Console 是什么

ICE3 Agent Console 是一个面向工业数字孪生和智慧水务的 3D 场景在线演示。 页面主体是一座完全虚构的市政污水处理厂，包含进水预处理、AAO 生化池、 二沉池、深度处理、污泥处理、曝气、加药、出水在线监测和事故池等工艺设备。 用户可以在三维场景中选择设备并查看名称、设备编号、工艺段、区域和流程连接。

Agent 通过受控的 Scene Tool 查询设备、选择设备、聚焦设备、高亮设备和切换相机。 内置剧本可以自动完成全厂巡游和多个工艺专题；场景采用 Prepared GLB， 并根据当前相机工作集加载粗模与细模，保持设备选择身份和可见覆盖稳定。

页面能力

  • 使用鼠标旋转和缩放，使用方向键或 WASD 在场景中移动。
  • 点击设备后显示黄色高亮和右上角设备信息浮层。
  • 通过对话或快捷剧本查看进水、生化、二沉池、深度处理和污泥处理流程。
  • 浏览器本地剧本无需账号、API key 或服务端即可完整运行。
  • 部署时也可以配置服务端 AI 模型，并通过同一界面驱动 Scene。

技术背景

示例建立在独立 ICE3 3D Runtime 之上，使用 WebGL2、OGC 3D Tiles 1.1、 Prepared GLB、层级 LOD、静态合批和设备语义标识。浏览器侧不执行模型格式转换， 源模型检查、切分和粗模生成由离线工具链完成。

源码与相关工程： Agent Console、 ICE3 Engine、 Industrial Core、 Toolchain、 Documentation。
